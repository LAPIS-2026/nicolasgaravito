# Códigos para Práctico — Prof. Nicolás Garavito (LAPIS 2026)

Repositorio de materiales y códigos para el práctico del Profesor Nicolás Garavito en la escuela de astrofísica **LAPIS 2026**.

## Estructura

- `LAPIS26/` — Submódulo con el fork de [jngaravitoc/LAPIS26](https://github.com/jngaravitoc/LAPIS26) en [`LAPIS-2026/LAPIS26`](https://github.com/LAPIS-2026/LAPIS26).

## Cómo clonar este repositorio (incluyendo submódulos)

```bash
git clone --recurse-submodules https://github.com/LAPIS-2026/nicolasgaravito.git
```

Si ya clonaste el repositorio sin `--recurse-submodules`, inicializa y descarga todos los submódulos con:

```bash
git submodule update --init --recursive
```
